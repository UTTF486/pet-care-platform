## 1. 启动顺序（必须按 1 → 2 → 3）

启动顺序不能反：前端依赖后端接口，后端依赖 Redis 和 MySQL。**MySQL 一般是开机自启的服务，确认它在跑就行。**

### ① 启动 Redis（第 1 个 cmd 窗口）

```bat
cd /d C:\redis
redis-server.exe redis.windows.conf
```

窗口里出现 `Ready to accept connections` 就成功了，**这个窗口不要关**。

再开一个窗口验证：

```bat
cd /d C:\redis
redis-cli.exe -a 你的Redis密码 ping
```

返回 `PONG` 即正常。会先打一行 `Warning: Using a password with '-a'...`，那是安全提示，忽略。

### ② 启动后端（第 2 个 cmd 窗口）

```bat
cd /d "C:\Users\dhl\Desktop\智慧宠物上门服务平台\backend"
mvn spring-boot:run
```

**成功标志**（大约 5~15 秒）：

```
Tomcat started on port(s): 8080 (http) with context path ''
Started PetCareApplication in 2.0 seconds
```

也可以在 IDEA 里直接运行 `PetCareApplication`，效果一样。IDEA 里跑要先确认 `Project SDK` 已就绪（推荐 17）。

> **密码放在哪**：仓库里不含任何真实密码，`application.yml` 全部是 `${环境变量:默认值}`。
> 本机密码写在 `backend/src/main/resources/application-local.yml`（该文件被 git 忽略）。
> 如果这个文件丢了，把同目录下 `application-local.yml.example` 复制一份改名为 `application-local.yml` 并填入密码即可。

快速验证后端通不通（浏览器直接打开）：

```
http://localhost:8080/api/services/hot
```

能看到一长串 JSON 就说明后端 + MySQL + Redis 全通了。

### ③ 启动前端（第 3 个 cmd 窗口）

```bat
cd /d "C:\Users\dhl\Desktop\智慧宠物上门服务平台\frontend"
npm run dev
```

**成功标志**：

```
VITE v5.4.21  ready in 483 ms
➜  Local:   http://localhost:5173/
```

浏览器会自动打开（`vite.config.js` 里配了 `open: true`）。没弹出就手动访问 http://localhost:5173 。

## 2. 自测清单（照着点，10 步走完主链路）

| # | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | `admin / 123456` 登录 | 自动进入「数据看板」，4 个指标卡有数字，折线图有最近 7 天数据 |
| 2 | 右上角切「按周」「按月」 | 图表重新聚合，X 轴标签变化 |
| 3 | 退出，`demo / 123456` 登录 | 进入用户端首页，顶部有「热门推荐」并标着 `Redis 缓存` 标签 |
| 4 | 点任意服务 → 选宠物、日期（今天或以后）、时段 → 确认预约 | 提示「预约成功」，跳到我的订单，状态 **待接单**，金额与服务单价一致 |
| 5 | 该订单点「催单」 | 提示「已提醒商家」；**再点一次**提示「已经催过啦」← Redis 去重生效 |
| 6 | 换 `admin` 登录 → 订单审核 | 刚才的单排在最上面，点「接单」选服务师 → 状态变 **待服务**，服务师列有名字 |
| 7 | 该订单点「完成」 | 状态变 **已完成**；到「服务管理」看该服务销量 +1 |
| 8 | 回 `demo` → 我的订单 → 去评价 | 打 5 星提交，按钮变「已评价」；再点会提示已评价过 |
| 9 | 后台 → 服务管理 → 下架某个服务 | 用户端首页该服务消失（缓存已清）；再上架又出现 |
| 10 | 后台 → 用户管理 → 禁用 `lily` | 提示已禁用；若 lily 正在登录状态，下次操作直接被踢回登录页 |

补充两个可以演示的「技术点」：

- **越权拦截**：用 `demo` 的 token 直接请求 `http://localhost:8080/api/admin/users` → 返回 `{"code":403,"message":"没有操作权限"}`（浏览器直接打开不行，需要带 Header，用 Postman 试）
- **限流**：连续快速下单第 6 次 → 提示「下单太频繁了，休息一下再试」（5 次/60 秒）

### 验证「超时自动取消」

1. 把 `backend/src/main/resources/application.yml` 里 `timeout-minutes: 30` 改成 `1`
2. 重启后端（Ctrl+C 后重新 `mvn spring-boot:run`）
3. 下一单，**不要接单**，等 2 分钟（任务每分钟跑一次）
4. 订单自动变「已取消」，取消原因「超时未接单，系统自动取消」，消息中心里能看到通知
5. 测完记得改回 `30`

## 3. 停止所有服务

| 服务 | 停止方式 |
| --- | --- |
| 后端 | 在它的窗口按 `Ctrl + C` |
| 前端 | 在它的窗口按 `Ctrl + C` |
| Redis | `cd /d C:\redis` 然后 `redis-cli.exe -a 你的Redis密码 shutdown nosave` |

`nosave` 表示不落盘，避免覆盖 `C:\redis\dump.rdb`（那是缓存数据，丢了无所谓，但别动你的文件）。

**窗口关了但端口还占着**？按端口强杀：

```bat
netstat -ano | findstr :8080
taskkill /F /PID <上面查到的PID>
```

5173、6379 同理换端口号。

> 关机重启后，后端和前端都要重新启动，Redis 也要重新起——它们都不是 Windows 服务。

## 4. 常见问题速查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 页面能开，但列表空白、弹「网络异常」 | 后端没起 / 数据库密码不对 | 先访问 `http://localhost:8080/api/services/hot` 确认后端 |
| 后端启动报 `Access denied for user 'root'` | `application-local.yml` 里的密码与本机 MySQL 不一致 | 改 `application-local.yml` 的 `spring.datasource.password` |
| 后端启动报 `Unable to connect to Redis` | Redis 没起或密码不对 | 起 Redis；确认 `application-local.yml` 里 `spring.redis.password` |
| 后端启动报 `Port 8080 was already in use` | 上一个后端没退干净 | 按上面「按端口强杀」处理 |
| IDEA 编译一堆「找不到符号」 | IDEA 用的 JDK 太高导致 Lombok 失效 | Maven 面板点 Reload → Rebuild；仍不行就把 Project SDK 设为 17 |
| 切换 JDK 后报 `Input length = 1` | `target` 里有另一 JDK 写的缓存 | `mvn clean` 一次 |
| 看板数字没立刻变 | 指标卡有 60 秒缓存 | 等 1 分钟刷新，或重启后端 |
| 想清空重来 | 测试数据越攒越多 | 见下方「重置数据」 |

## 6. 可选：纯接口自测（不打开页面）

用 Git Bash 或 Postman，cmd 里 curl 的 JSON 引号需要转义，容易出错。

```bash
BASE=http://localhost:8080/api

# 1) 登录拿 token
curl -s -X POST $BASE/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"123456"}'

# 2) 查热门服务（游客可访问）
curl -s $BASE/services/hot

# 3) 下单（把 TOKEN 换成上一步的返回值）
curl -s -X POST $BASE/orders \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer TOKEN" \
  -d '{"petId":1,"serviceId":1,"appointDate":"2026-11-22","timeSlot":"10:00-12:00","contactName":"小李","contactPhone":"13800000002","address":"杭州市西湖区文三路100号"}'
```

完整接口清单见 `docs/03-接口文档.md`。

## 7. 最小启动脚本（可选，自己建）

如果嫌每次开三个窗口麻烦，可以在项目根目录建两个 `.bat`（注意保存为 **ANSI/GBK** 编码，否则 cmd 里中文乱码）：

```bat
:: start-backend.bat
@echo off
cd /d "%~dp0backend"
mvn spring-boot:run
```

```bat
:: start-frontend.bat
@echo off
cd /d "%~dp0frontend"
npm run dev
```

Redis 建议单独一个窗口，方便看日志。
