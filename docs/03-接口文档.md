# 03 · 接口文档

- 基础路径：`http://localhost:8080/api`
- 认证方式：请求头 `Authorization: Bearer {token}`
- 统一返回：`{ "code": 200, "message": "操作成功", "data": ... }`
- 业务码：200 成功 / 400 参数错误 / 401 未登录 / 403 无权限 / 404 不存在 / 429 限流 / 500 系统异常
- 分页参数：`pageNum` 从 1 开始，`pageSize` 默认 10（服务列表 8、我的订单 5）

## 1. 认证

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/register` | 否 | 注册，成功直接返回 token |
| POST | `/auth/login` | 否 | 登录 |
| POST | `/auth/logout` | 是 | 退出，删除 Redis 登录态 |
| GET | `/auth/profile` | 是 | 当前用户信息 |

**POST /auth/login**

```json
// 请求
{ "username": "demo", "password": "123456" }

// 响应
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "8f3c1a9e4b7d4c2fa1e6...",
    "user": {
      "id": 2, "username": "demo", "nickname": "铲屎官小李",
      "phone": "13800000002", "role": 0, "status": 1,
      "createTime": "2026-11-20 15:20:00"
    }
  }
}
```

> `password` 字段在实体上是 `@JsonIgnore`，任何接口都不会返回密码。

## 4. 订单（用户端）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/orders` | 下单（限流：5 次/60 秒） |
| GET | `/orders` | 我的订单，参数 `status`（0/1/2/3，不传为全部）、`pageNum`、`pageSize` |
| GET | `/orders/{id}` | 订单详情（含归属校验） |
| PUT | `/orders/{id}/cancel` | 取消，参数 `reason` |
| POST | `/orders/{id}/urge` | 催单（5 分钟内仅一次） |
| POST | `/orders/review` | 评价 |

**POST /orders**

```json
{
  "petId": 1,
  "serviceId": 1,
  "appointDate": "2026-11-22",
  "timeSlot": "10:00-12:00",
  "contactName": "小李",
  "contactPhone": "13800000002",
  "address": "杭州市西湖区文三路 100 号 3-502",
  "remark": "钥匙放门口鞋柜"
}
```

> 不传 `amount`。金额由后端按 `t_service.price` 计算，防前端改价。可选时段：`08:00-10:00`、`10:00-12:00`、`14:00-16:00`、`16:00-18:00`、`18:00-20:00`。

**overview 响应**

```json
{
  "code": 200,
  "data": {
    "todayOrderCount": 2,
    "todayRevenue": 167.00,
    "totalOrderCount": 8,
    "totalRevenue": 484.00,
    "pendingCount": 1,
    "userCount": 3,
    "goodRate": 80.0,
    "avgRating": 4.40,
    "onSaleServiceCount": 7
  }
}
```

**trend 响应**

```json
{
  "code": 200,
  "data": [
    { "label": "2026-11-14", "orderCount": 1, "revenue": 49.00 },
    { "label": "2026-11-15", "orderCount": 1, "revenue": 128.00 },
    { "label": "2026-11-16", "orderCount": 2, "revenue": 0.00 }
  ]
}
```

> `revenue` 只统计已完成订单（status=2）。在途和已取消的钱不是收入。
> 没有订单的日期不会出现在结果里，前端画图时如需补零可在前端处理（本项目直接展示真实有数据的点）。

## 10. 用 curl 快速自测

```bash
# 登录拿 token
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"123456"}'

# 带 token 查我的订单（把 TOKEN 换成上一步返回值）
curl http://localhost:8080/api/orders?pageNum=1&pageSize=5 \
  -H "Authorization: Bearer TOKEN"

# 下单
curl -X POST http://localhost:8080/api/orders \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer TOKEN" \
  -d '{"petId":1,"serviceId":1,"appointDate":"2026-11-22","timeSlot":"10:00-12:00","contactName":"小李","contactPhone":"13800000002","address":"杭州市西湖区文三路100号"}'
```

> Windows PowerShell 里 curl 是 `Invoke-WebRequest` 的别名，建议用 Git Bash 执行，或用 Postman。
